# Product Vision

## Working Definition

A virtual collaborative game development studio presented as a top-down 2D workspace.

The experience combines the clarity of project management tools with the social presence of a virtual studio.

The application should feel closer to:

```text
Trello / lightweight project tracking
+
Slack / team communication
+
virtual 2D studio presence
```

but must retain its own identity.

## Main Purpose

The application exists to solve three problems:

1. Team communication feels fragmented across tools.
2. Leads cannot quickly understand current progress and blockers.
3. Team members lose the feeling of working together when using many separate production tools.

## Key Principle

The app does not become the production tool.

Examples:

```text
Programming → GitHub / IDE
Art → Figma / Photoshop / Blender
Design → Figma / FigJam / external docs
Writing → Notion / Google Docs
Audio → DAW
```

The application connects those activities through:

- status
- links
- embeds
- structured reports
- progress
- conversation
- presence

## User Experience

A member can:

1. Enter the virtual studio.
2. See who is currently online.
3. Walk to another member or room.
4. Start a conversation.
5. Inspect project goals or individual progress.
6. Open an embedded external work preview.
7. Continue work in the external tool.
8. Submit a progress update.
9. Allow leads to monitor project health.

## Product Identity

The virtual studio is not decoration.

Every meaningful room or interactive object should provide useful context or access to work information.

Examples:

- monitor → current work / external embed
- desk → member progress
- project board → project status
- meeting table → group context
- room → contextual communication channel
