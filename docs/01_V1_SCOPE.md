# V1 Scope

## V1 Objective

Deliver a usable team communication and project-progress workspace with an interactive 2D studio.

V1 is successful when:

- members can authenticate
- members belong to a workspace/project
- avatars can coexist in a studio
- members can communicate
- project progress can be tracked
- external work can be referenced
- leads can monitor project status

## Included

### Accounts
- register
- login
- logout
- profile
- avatar identity
- team/workspace membership

### Roles
Initial recommended product roles:

- Owner
- Lead
- Member
- Guest

Professional discipline is separate metadata:

- Programmer
- Artist
- Game Designer
- Audio
- Writer
- QA
- Producer
- Other

Do not use discipline as the main permission system.

### Virtual Studio
- top-down 2D map
- avatar movement
- collision
- basic rooms
- basic interactable objects
- online presence
- visible remote avatars

### Communication
- direct messages
- group conversations
- room conversations
- basic unread indicator
- online state
- typing state
- quick chat bubble or lightweight studio indication

### Project System
- project
- milestone
- goal
- task
- assignee
- due date
- progress
- status
- blocker
- review state

### Reporting
- structured progress updates
- progress history
- summary
- blockers
- next target
- evidence links
- lightweight attachments where appropriate

### External References
- generic link
- supported embed where possible
- Figma/FigJam-ready architecture
- fallback preview card
- external open action

### Lead Monitoring
- project progress
- milestone progress
- member progress
- blocked items
- overdue items
- review queue
- recent updates

### Views
- Studio View
- Board/Monitoring View

## Not Included in V1

- voice chat
- video chat
- AI assistant
- full Discord replacement
- full Notion replacement
- full Jira replacement
- project file repository for large assets
- large game build hosting
- built-in source code editing
- built-in art/design editing
- advanced analytics
- advanced automation
- public community features
- monetization
